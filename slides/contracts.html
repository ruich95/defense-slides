Specifying Component Behaviour

Linear types constrain interfaces and composition, but do not fully specify component behaviour.

Dependent types let us specify the required behaviour.

The resulting law becomes a contract on implementations.

spec : (st : !* a) -> (x : a) ->
       (get =<< set) x st
       = get () (MkBang x)
