Specifying Component Behaviour

Linear use alone does not specify component behaviour.

regBad — setter excerpt

set : Component (!* a) a ()
set x st = st # ()

Well typed, but the stored value is unchanged.

Add a behavioural contract

spec : (st : !* a) -> (x : a) ->
       (get =<< set) x st = get () (MkBang x)

Writing and then reading must agree with reading the updated state.

Reading an address after writing it returns the written value.

Reason about a component
through its contract.

A foreign implementation needs evidence for the contract.

Read preserves state:
a C memory-read contract verified using ACSL.
