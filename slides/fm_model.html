Building the FM Receiver in SynQ

The receiver is built as a hierarchy of SynQ components.

  • Hierarchical composition: model each DDC from a mixer, CIC decimator and compensation filter.
  • Linear resource tracking checks that each bundled resource is used exactly once.
  • Configurable truncation: each accumulator truncates its output to a selected bit width.
    • Type-level configuration: specify accumulator widths and input/output widths.
    • Type checking infers each accumulator’s input and output widths.

    Type checking ensures consistent widths; the inferred widths determine the truncation parameters.
