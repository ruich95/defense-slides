Building the FM Receiver in SynQ

The receiver is built as a hierarchy of SynQ components.

  • Hierarchical composition: model each DDC from a mixer, CIC decimator and compensation filter.
  • Linear resource tracking: bundle resources hierarchically and enforce their use exactly once.
  • Configurable truncation: each accumulator truncates its output to a selected bit width.
    • Type-level configuration: specify accumulator widths and input/output widths.
    • Inferred parameters: infer each accumulator’s input and output widths during type checking.

    Truncation parameters are calculated from the inferred widths.

@@FM_HIERARCHY_SVG@@
cicInt4: (Seq comb seq, Primitive comb)
  => (1 regs:
       CICIntRegs [44, 37, 31, 26] comb seq)
  -> seq (CICIntSt [44, 37, 31, 26])
         (BitVec 44) (BitVec 23)
cicInt4 (r1 # r2 # r3 # r4) = 
  intStg' r4 <<< intStg' r3
    <<< intStg' r2 <<< intStg' r1
