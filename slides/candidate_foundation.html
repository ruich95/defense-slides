A Candidate Language Foundation

A general-purpose functional language with dependent types could host a component-based design framework.

  • Atomic components as constants.
  • Composition operators as functions that combine components.
  • Transformations as functions from models to models.

Embedding lets designers reuse the host language’s abstractions, type checker and tools.
