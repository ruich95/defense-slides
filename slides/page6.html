Type Theory Beyond Interactive Theorem Proving

@@PAGE6_PAPERS@@

Languages based on type theory support general-purpose programming alongside interactive theorem proving.

  • Programming lets us define executable models and reusable design steps.
  • Formal reasoning lets us state properties of models and design steps.

This opens the possibility of embedding a component-based design framework in the same language we use to reason about its models and design steps.
