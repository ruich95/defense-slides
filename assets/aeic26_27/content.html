Input shape: a witness that the input is built from values of type a; inferred here by the type checker.
Binary operator: combines two values of type a into one.
Single value: return it unchanged.
Pair: reduce each part, then combine the two results.
The input type determines this reducer’s structure.
The balance-tree transformation:
Given an input collection and its shape witness.
Compute a new input type and reshaped collection, then regenerate the reducer.
Behaviour preservation is proved in Idris2, assuming associativity.
